# Reglas del Proyecto
- Estamos construyendo un CRM Omnicanal Multi-tenant para WhatsApp (SaaS).
- **Backend:** Node.js, Express, Mongoose (MongoDB).
- **Frontend:** HTML5, CSS3 puro y Vanilla JavaScript. NO usar React, NO usar frameworks pesados.
- **Estilo de código:** Usar ES Modules (`import`/`export`), async/await para asincronía. 
- **Diseño:** Minimalista, estilo dashboard SaaS profesional, paleta de colores limpia, diseño 100% responsivo.
- **Idioma:** Nombramos variables y comentamos el código en español.
